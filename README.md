# Renewal Match operations

Product-owned retention and operational monitoring. The application stays on Sites/Cloudflare. This repository contains no customer records, catalogs, or credentials. The existing VPS fallback remains until independent acceptance.

The default-branch workflow runs on standard hosted Linux runners at minutes 17 and 47 UTC, executes fixed-policy cleanup and verifies the persisted receipt, alerts the owner on failure and records recovery. Production stays disabled until its separate encrypted credential is configured after accepted deployment. A monthly operational commit prevents inactive scheduled-workflow disablement. Public source does not grant access to the maintenance endpoint.
